Home Assistant integration

A custom integration installed through HACS, so we can look after clients' Home Assistant setups remotely from the ERP.

Its own sidebar panel

Visible only to the easydomotica Home Assistant user. No separate passwords.

SmartThings auto-reload

Reloads every 10 minutes, configurable, to keep the integration stable.

Reload scheduler

Per-client schedules by hour, day and interval, with logs saved to the NAS.

Update checker

Reads live states and spots pending updates for integrations, Core and OS, retrying every 15 minutes.

Authenticated REST API

Every endpoint requires the Home Assistant token and answers 403 to anything else.

# only this HA user gets in
ALLOWED_USERNAME = "easydomotica"

# auto-reload every 10 min
RELOAD_INTERVAL = timedelta(minutes=10)

# every view needs HA auth
requires_auth = True

if not _is_authorized(request):
    return json_response(
        {"error": "Accesso negato"},
        status=403)
